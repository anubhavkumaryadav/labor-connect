# labor-connect
A mobile-first, bilingual (Hindi/English) web portal connecting construction contractors and daily-wage laborers directly, featuring anti-spam contact protection and PIN-secured post management powered by Supabase.
#  MyLabor11 (निर्माणसेतु)
**Direct, Secure & Bilingual Construction Labor Marketplace**

MyLabor11 is a mobile-first web platform designed to bridge the gap between daily-wage construction workers and contractors/site supervisors. It eliminates middlemen, enabling direct hiring while protecting workers from spam and phone scraping.

---

###  Key Features

* **Two-Sided Platform:** 
  * **Contractor View:** Search and filter active workers by city area and trade (Mason, Helper, Painter, Electrician).
  * **Laborer View:** Find nearby construction sites, daily wage rates, and work requirements.
* **Bilingual Support (English & हिंदी):** One-click full-interface translation designed for varying digital literacy levels.
* **Anti-Spam Contact Protection:** Phone numbers are masked by default (`98•••• 210`) and require verified access to unlock, preventing automated scraping and harassment.
* **PIN-Protected Deletion:** Users assign a 4-digit security PIN to listings, allowing easy removal once work or workers are secured.
* **Cloud Database & Multi-Device Sync:** Backed by Supabase (PostgreSQL) for instant live updates across all connected devices.

---

###  Tech Stack

* **Frontend:** HTML5, Tailwind CSS (Mobile-First UI), Vanilla JavaScript
* **Database & Cloud:** Supabase (PostgreSQL, REST API, Row Level Security)
* **Icons:** FontAwesome
* **Deployment:** GitHub Pages / Netlify
